    8. 与服务器通信

    本章的示例会查询 JSON 服务器 [RdvMedecins]：它必须处于运行状态（在 [npm run start:dev] 文件夹 [rdvmedecins-nestjs-json] 中，端口 8080），并与端口 4200 上的 [Angular] 开发服务器同时运行。

    8.1. 示例 22：第一个 HTTP 请求

    8.1.1. 开发服务器的代理

    示例页面来自 http://localhost:4200（[Angular] 开发服务器，由 [ng serve] 启动）；API 位于 http://localhost:8080。对浏览器而言，这是两个不同的 源 （端口是源的一部分）。然而，出于安全原因，除非服务器明确允许（即所谓的 CORS 机制），浏览器不允许页面读取来自另一个源的响应。并且发往另一个源的请求不会携带 Cookie（因此也不会携带令牌），除非代码请求这样做（[withCredentials: true]）并且服务器也接受，这同样要通过 CORS 实现。

    我们不向其他源开放服务器，而是让 API 请求经由 [Angular] 开发服务器转发。这就是 代理 ，声明于工作区文件 [proxy.conf.json]：

// 22-httpclient/src/app/app.ts - a first HTTP request to the server
// -------------------------------------------------------------------------
// The RdvMedecins JSON server must be running (port 8080). We ask it for
// a captcha: GET /api/captcha -> { "id": "...", "svg": "<svg ...>" }.
//
//   - HttpClient: the HTTP client of Angular (provided by default to the whole
//     application). http.get<T>(url) returns an OBSERVABLE (see example
//     19): the request is only sent when we SUBSCRIBE to it (subscribe);
//     the JSON response arrives already converted into an object, of the announced type T;
//   - the address is RELATIVE (/api/captcha): the request goes to the
//     server of the page, that of Angular (port 4200), which forwards it to the
//     JSON server (port 8080) thanks to its proxy (see proxy.conf.json);
//   - three states to display: loading, success, error.
// =========================================================================

import { Component, computed, inject, signal } from '@angular/core';
import { HttpClient, HttpErrorResponse } from '@angular/common/http';
import { DomSanitizer, SafeHtml } from '@angular/platform-browser';

// what GET /api/captcha returns
interface Captcha {
  id: string;
  svg: string;
}

@Component({
  selector: 'app-root',
  templateUrl: './app.html',
  styles: `
    .captcha {
      display: inline-block;
      border: 1px solid #dee2e6;
      border-radius: 0.375rem;
    }
  `,
})
export class App {
  private readonly http = inject(HttpClient);
  private readonly sanitizer = inject(DomSanitizer);

  protected readonly captcha = signal<Captcha | null>(null);
  protected readonly loading = signal(false);
  protected readonly error = signal<string | null>(null);
  protected readonly requestCount = signal(0);

  // [innerHTML] inserts a string as HTML. For security, Angular
  // CLEANS this HTML ("sanitization"): it removes the scripts... and the
  // <svg> tags. bypassSecurityTrustHtml tells Angular: "this HTML is
  // safe, do not clean it". To be used ONLY for safe content: this SVG
  // is built by OUR server. With user input, it would be
  // opening the door to script injection ({{ }}, on the other hand, escapes everything).
  protected readonly svg = computed<SafeHtml | null>(() => {
    const c = this.captcha();
    return c ? this.sanitizer.bypassSecurityTrustHtml(c.svg) : null;
  });

  constructor() {
    this.load(); // at startup, we load a captcha
  }

  protected load(): void {
    this.loading.set(true);
    this.error.set(null);
    this.http.get<Captcha>('/api/captcha').subscribe({
      // next: the response (2xx code), already converted from JSON
      next: (captcha) => {
        this.captcha.set(captcha);
        this.requestCount.update((n) => n + 1);
        this.loading.set(false);
      },
      // error: a 4xx / 5xx response, or no response at all (status 0)
      error: (e: HttpErrorResponse) => {
        this.error.set(`the server answered ${e.status} ${e.statusText}`);
        this.captcha.set(null);
        this.loading.set(false);
      },
    });
  }
}
    • 第 22 行：来自 [GET /api/captcha] 的响应格式；
    • 第 39 行：注入 HTTP 客户端；
    • 第 42–45 行：请求的三种状态：进行中、成功（得到验证码）和错误；
    • 第 65 行：[http.get<Captcha>(url)] 准备一个 GET 请求。它返回一个可观察对象 （示例 19）：只有在被订阅（[subscribe]）时才会发送请求。该地址是相对地址：请求被发送到页面所在的服务器，再由它转发给 JSON 服务器；
    • 第 67–71 行：[next] 接收已从 JSON 转换好的响应。[<Captcha>] 向 [TypeScript] 说明对象的格式：编译器无法验证服务器将发送什么；
    • 第 73–77 行：[error] 会在收到任何 4xx 或 5xx 响应时接收一个 [HttpErrorResponse] ，在没有收到响应时（服务器宕机、网络断开：此时 [status] 为 0）也是如此。如果 JSON 服务器宕机，代理会以 5xx 错误响应；
    • 第 59 行：启动时加载一个验证码（CAPTCHA）；
    • 第 53–56 行：来自验证码（CAPTCHA）的 SVG 图像是一个字符串，必须作为 HTML 插入（模板中的 [[innerHTML]] ）。出于安全原因，[Angular] 会清理以这种方式插入的任何 HTML：它会移除脚本……以及 [<svg>] 标签。[bypassSecurityTrustHtml] 表明这段 HTML 是安全的。我们只对安全内容使用它：这个 SVG 由我们自己的服务器生成。对于用户输入的数据，这会允许脚本被注入页面；而双花括号 [{{ }}] 则会对一切进行转义。

    // =========================================================================
// 23-login/src/app/app.ts - logging in to the RdvMedecins server
// -------------------------------------------------------------------------
//   1. at startup: GET /api/auth/me - are we already logged in?
//      (after an F5, the client has forgotten everything; the server reads the cookie);
//   2. login: POST /api/auth/login, JSON body { login, password,
//      captchaId, captcha }. On success, the server sets the
//      httpOnly cookie of the JWT token: our code NEVER sees it (try
//      document.cookie in the console: it is not there);
//   3. protected request: GET /api/doctors. The browser attaches the cookie
//      to it by itself (same origin);
//   4. logout: POST /api/auth/logout - the server deletes the cookie.
//
// firstValueFrom(observable): a PROMISE of the first value of the stream.
// Chains of requests can then be written with async / await,
// more readable than a cascade of subscribe. An error response rejects
// the promise with an HttpErrorResponse: a simple try / catch.
//
// A cookie belongs to a machine (localhost) and to a path (/api): it
// is therefore common to ALL the examples. Once logged in here, examples
// 24 and 25 are logged in too.
// =========================================================================

import { Component, computed, inject, signal } from '@angular/core';
import { HttpClient, HttpErrorResponse } from '@angular/common/http';
import { DomSanitizer } from '@angular/platform-browser';
import { FormsModule } from '@angular/forms';
import { firstValueFrom } from 'rxjs';

interface User {
  login: string;
  name: string;
  role: 'ADMIN' | 'DOCTOR' | 'USER';
}
interface Doctor {
  id: number;
  title: string;
  firstName: string;
  lastName: string;
}
interface Captcha {
  id: string;
  svg: string;
}
// the shape of ALL the errors of the API
interface ApiError {
  statusCode: number;
  key: string;
  params?: Record<string, string>;
}

// the few messages this example needs (example 25 will use ngx-translate)
const MESSAGES: Record<string, string> = {
  'LOGIN.ERROR': 'Incorrect login or password.',
  'ERRORS.WRONG_CAPTCHA': 'The characters you typed do not match the image.',
  'ERRORS.TOO_MANY_ATTEMPTS': 'Too many failed attempts. Try again later.',
};

@Component({
  selector: 'app-root',
  imports: [FormsModule],
  templateUrl: './app.html',
})
export class App {
  private readonly http = inject(HttpClient);
  private readonly sanitizer = inject(DomSanitizer);

  protected readonly user = signal<User | null>(null);
  protected readonly doctors = signal<Doctor[]>([]);
  protected readonly captcha = signal<Captcha | null>(null);
  protected readonly svg = computed(() => this.sanitizer.bypassSecurityTrustHtml(this.captcha()?.svg ?? ''));
  protected readonly login = signal('admin');
  protected readonly password = signal('');
  protected readonly captchaAnswer = signal('');
  protected readonly error = signal<string | null>(null);
  protected readonly ready = signal(false); // is the initial check finished?

  constructor() {
    this.checkSession().catch(() => {
      this.error.set('Is the RdvMedecins JSON server running (port 8080)?');
      this.ready.set(true);
    });
  }

  protected async loadCaptcha(): Promise<void> {
    this.captcha.set(await firstValueFrom(this.http.get<Captcha>('/api/captcha')));
    this.captchaAnswer.set('');
  }

  // 1. who is logged in? 200 -> the user; 401 -> nobody
  private async checkSession(): Promise<void> {
    try {
      this.user.set(await firstValueFrom(this.http.get<User>('/api/auth/me')));
      await this.loadDoctors();
    } catch (e) {
      if (!(e instanceof HttpErrorResponse) || e.status !== 401) {
        throw e; // not a 401: the server does not respond
      }
      await this.loadCaptcha();
    }
    this.ready.set(true);
  }

  // 2. the login; post(url, body): the body is sent as JSON
  protected async logIn(): Promise<void> {
    this.error.set(null);
    try {
      const u = await firstValueFrom(
        this.http.post<User>('/api/auth/login', {
          login: this.login(),
          password: this.password(),
          captchaId: this.captcha()?.id,
          captcha: this.captchaAnswer(),
        }),
      );
      this.user.set(u);
      this.password.set('');
      await this.loadDoctors();
    } catch (e) {
      // e.error: the JSON body of the error response
      const apiError = (e as HttpErrorResponse).error as ApiError | null;
      const key = apiError?.key ?? 'ERRORS.SERVER_UNREACHABLE';
      this.error.set(`${(e as HttpErrorResponse).status} - ${MESSAGES[key] ?? key}`);
      await this.loadCaptcha(); // each image is only used once
    }
  }

  // 3. a protected request
  private async loadDoctors(): Promise<void> {
    this.doctors.set(await firstValueFrom(this.http.get<Doctor[]>('/api/doctors')));
  }

  // 4. the logout
  protected async logOut(): Promise<void> {
    await firstValueFrom(this.http.post('/api/auth/logout', {}));
    this.user.set(null);
    this.doctors.set([]);
    await this.loadCaptcha();
  }
}
    • 第 30–50 行：与服务器交换的数据格式，包括 API 所有错误的格式（第 46–50 行）；
    • 第 53–57 行：本示例所需的少量消息，使用英文；示例 25 将使用 [ngx-translate]；
    • 第 28 行：[firstValueFrom(observable)] 返回一个关于流中第一个值的 Promise 。HTTP 请求只产生一个值——响应：这样我们就可以使用 [async] / [await] 编写请求链，这比层层嵌套的 [subscribe] 更易读。错误响应会使 Promise 被拒绝（rejected）：一个简单的 [try / catch] 就能捕获它；
    • 第 91–102 行：启动时执行 [GET /api/auth/me]：我们是否已经登录？重新加载页面（F5）之后，[Angular] 应用忘记了一切；然而服务器会读取 Cookie。200：返回用户；401：无人登录——这种情况下会显示登录表单及其验证码（CAPTCHA）（第 99 行）；

    • 第 105–126 行：登录：
      • 第 109 行：[http.post(url, body)]：对象 [body] 以 JSON 形式发送，并带有请求头 [Content-Type: application/json]；

// common/api-error.ts - ONE class for all the errors of the API
// -------------------------------------------------------------------------
// All the error responses of the RdvMedecins server have the same shape:
//   { "statusCode": 409, "key": "ERRORS.LOGIN_TAKEN", "params": {...}, "fields": {...} }
// HttpClient reports them with an HttpErrorResponse, whose error property
// contains this JSON body... or something else: null (no response), text
// (an error page of the proxy when the JSON server is stopped). We
// convert all of this into ONE class, ApiError, which carries the translation
// key sent by the server (and, if any, its parameters and
// the error of each field).
// =========================================================================

import { HttpErrorResponse } from '@angular/common/http';

export class ApiError extends Error {
  constructor(
    public readonly statusCode: number, // 0: the server did not respond
    public readonly key: string, // e.g.: 'ERRORS.LOGIN_TAKEN'
    public readonly params: Record<string, string> = {},
    public readonly fields: Record<string, string> = {},
  ) {
    super(key);
    this.name = 'ApiError';
  }
}

// any error -> an ApiError
export function toApiError(e: unknown): ApiError {
  if (e instanceof ApiError) {
    return e;
  }
  if (!(e instanceof HttpErrorResponse)) {
    return new ApiError(0, 'ERRORS.SERVER_ERROR');
  }
  // the JSON body of the error, if it exists and has the right shape
  const body = (typeof e.error === 'object' && e.error !== null ? e.error : {}) as {
    key?: string;
    params?: Record<string, string>;
    fields?: Record<string, string>;
  };
  // no key: it is not our server that responded (proxy, network)
  const key = body.key ?? (e.status === 0 || e.status >= 500 ? 'ERRORS.SERVER_UNREACHABLE' : 'ERRORS.SERVER_ERROR');
  return new ApiError(e.status, key, body.params, body.fields);
}

import { FormsModule } from '@angular/forms';
import { LoginBar } from '../../../common/login-bar';

function tomorrow(): string {
  const d = new Date(Date.now() + 24 * 3600 * 1000);
  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`;
}

@Component({
  selector: 'app-root',
  imports: [FormsModule, LoginBar],
  templateUrl: './app.html',
})
export class App {
  private readonly rdv = inject(RdvMedecinsService);

  protected readonly user = signal<User | null>(null);
  protected readonly doctors = signal<Person[]>([]);
  protected readonly clients = signal<Person[]>([]);
  protected readonly doctorId = signal<number | null>(null);
  protected readonly day = signal(tomorrow());
  protected readonly clientId = signal<number | null>(null);
  protected readonly message = signal<{ type: 'success' | 'danger'; text: string } | null>(null);

  protected readonly isManager = computed(() => this.user() !== null && this.user()?.role !== 'USER');

  // undefined: no request (no doctor chosen, or nobody logged in)
  protected readonly schedule = httpResource<Schedule>(() => {
    const id = this.doctorId();
    return id === null || this.user() === null ? undefined : this.rdv.scheduleRequest(id, this.day());
  });

  // the error of the last request of the schedule, as an ApiError
  protected readonly scheduleError = computed(() => {
    const e = this.schedule.error();
    return e instanceof ApiError ? `${e.statusCode} ${e.key}` : null;
  });

  constructor() {
    // a new choice of doctor or day clears the previous message
    effect(() => {
      this.doctorId();
      this.day();
      this.message.set(null);
    });
  }

  protected timeRange(c: ScheduleSlot): string {
    const hm = (h: number, m: number) => `${h}:${String(m).padStart(2, '0')}`;
    return `${hm(c.startHour, c.startMinute)} - ${hm(c.endHour, c.endMinute)}`;
  }

  // an API error becomes a message (its key, for lack of a dictionary here)
  private report(e: unknown): void {
    this.message.set({ type: 'danger', text: e instanceof ApiError ? `${e.statusCode} ${e.key}` : String(e) });
  }

  // login / logout: we (re)load what this role is allowed to see
  protected async onUserChange(u: User | null): Promise<void> {
    this.user.set(u);
    this.doctors.set([]);
    this.clients.set([]);
    if (u === null) {
      return;
    }
    try {
      this.doctors.set(await this.rdv.getDoctors());
      // the list of patients: only for ADMIN and DOCTOR (a USER would receive 403)
      this.clients.set(this.isManager() ? await this.rdv.getClients() : []);
    } catch (e) {
      this.report(e);
    }
  }

  protected async book(c: ScheduleSlot): Promise<void> {
    try {
      await this.rdv.book(this.day(), c.id, this.isManager() ? (this.clientId() ?? undefined) : undefined);
      this.message.set({ type: 'success', text: `Slot ${this.timeRange(c)} booked.` });
    } catch (e) {
      this.report(e);
    }
    this.schedule.reload();
  }

  protected async cancel(c: ScheduleSlot): Promise<void> {
    try {
      await this.rdv.cancelAppointment(c.appointmentId as number);
      this.message.set({ type: 'success', text: `Appointment of ${this.timeRange(c)} cancelled.` });
    } catch (e) {
      this.report(e);
    }
    this.schedule.reload();
  }
}

// 25-server-errors/src/app/app.ts - displaying the errors of the SERVER
// -------------------------------------------------------------------------
// The management of the clients (admin account). This form
// DELIBERATELY does no validation in the browser: its schema is empty.
// Everything is sent to the server, which answers, in case of refusal, with a JSON
// error (converted into an ApiError by the interceptor):
//
//   400 { key: 'ERRORS.INVALID_FORM', fields: { lastName: 'ERRORS.LASTNAME_REQUIRED' } }
//   409 { key: 'ERRORS.PATIENT_ALREADY_EXISTS', fields: { firstName: ..., lastName: ... } }
//   409 { key: 'ERRORS.CONCURRENT_UPDATE' }         (optimistic lock)
//
// submit(form, action): the action sends the model to the server. If it
// returns ERRORS (an array), the signal forms attach them
// to the designated fields (fieldTree): they appear in f.lastName().errors(),
// like the errors of a validator. Their message is here the KEY sent by
// the server, which the template translates (ngx-translate). Try: an empty
// last name, a "Dr" title, a namesake (Alice DURAND), a login already taken
// (martin), the same record modified in two tabs...
// =========================================================================

import { Component, computed, inject, signal } from '@angular/core';
import { FormField, form, submit, ValidationError } from '@angular/forms/signals';
import { TranslatePipe, TranslateService } from '@ngx-translate/core';
import { ApiService } from '../../../common/api.service';
import { LoginBar } from '../../../common/login-bar';
import { ApiError } from '../../../common/api-error';
import { Person, User } from '../../../common/types';
// the confirmation dialog of example 16, reused as is
import { ConfirmationService } from '../../../16-confirmation/src/app/confirmation/confirmation.service';
import { ConfirmDialog } from '../../../16-confirmation/src/app/confirmation/confirm-dialog';

interface ClientInput {
  title: string;
  firstName: string;
  lastName: string;
  login: string;
  password: string;
  version: number;
}

const EMPTY: ClientInput = { title: 'Mr', firstName: '', lastName: '', login: '', password: '', version: 0 };

@Component({
  selector: 'app-root',
  imports: [FormField, TranslatePipe, LoginBar, ConfirmDialog],
  templateUrl: './app.html',
})
export class App {
  private readonly api = inject(ApiService);
  private readonly confirmation = inject(ConfirmationService);
  protected readonly translate = inject(TranslateService);

  protected readonly user = signal<User | null>(null);
  protected readonly clients = signal<Person[]>([]);
  protected readonly isAdmin = computed(() => this.user()?.role === 'ADMIN');

  // the form: editedId === null -> creation, otherwise update
  protected readonly editedId = signal<number | null>(null);
  protected readonly model = signal<ClientInput>({ ...EMPTY });
  protected readonly f = form(this.model); // no validator: the server validates
  // the general message of the last error, and that of a success
  protected readonly pageError = signal<ApiError | null>(null);
  protected readonly success = signal<{ key: string; params: Record<string, string> } | null>(null);

  protected async onUserChange(u: User | null): Promise<void> {
    this.user.set(u);
    this.clients.set([]);
    if (u?.role === 'ADMIN') {
      await this.reload();
    }
  }

  private async reload(): Promise<void> {
    this.clients.set(await this.api.get<Person[]>('/clients'));
  }

  protected newForm(): void {
    this.editedId.set(null);
    this.model.set({ ...EMPTY });
    this.f().reset(); // the state of the fields (and their errors) starts from zero
    this.clearMessages();
  }

  protected edit(c: Person): void {
    this.editedId.set(c.id);
    // the VERSION read with the record goes back with the update: if someone
    // has modified the record in the meantime, the server will answer 409 CONCURRENT_UPDATE
    this.model.set({ title: c.title, firstName: c.firstName, lastName: c.lastName, login: c.login ?? '', password: '', version: c.version });
    this.f().reset();
    this.clearMessages();
  }

  private clearMessages(): void {
    this.pageError.set(null);
    this.success.set(null);
  }

  // the error of EACH field, returned by the server -> an error of the form
  private fieldErrors(e: ApiError): ValidationError.WithOptionalFieldTree[] {
    const fields = Object.keys(this.model()) as (keyof ClientInput)[];
    return Object.entries(e.fields)
      .filter(([field]) => fields.includes(field as keyof ClientInput))
      .map(([field, key]) => ({ kind: 'server', message: key, fieldTree: this.f[field as keyof ClientInput] }));
  }

  protected async save(event: SubmitEvent): Promise<void> {
    event.preventDefault();
    this.clearMessages();
    const id = this.editedId();
    await submit(this.f, async () => {
      try {
        const body = this.model();
        const client =
          id === null
            ? await this.api.post<Person>('/clients', body)
            : await this.api.put<Person>(`/clients/${id}`, body);
        this.newForm(); // form cleared, messages cleared...
        // ... except this one
        this.success.set({
          key: id === null ? 'FORM.ADDED' : 'FORM.UPDATED',
          params: { name: `${client.firstName} ${client.lastName}`, login: client.login ?? '' },
        });
        await this.reload();
        return null;
      } catch (e) {
        if (!(e instanceof ApiError)) {
          throw e;
        }
        this.pageError.set(e); // the general message
        return this.fieldErrors(e); // the error of each field
      }
    });
  }

  protected async remove(c: Person): Promise<void> {
    const name = `${c.firstName} ${c.lastName}`;
    if (!(await this.confirmation.confirm(this.translate.instant('FORM.DELETE_CONFIRM', { name })))) {
      return;
    }
    this.clearMessages();
    try {
      await this.api.delete(`/clients/${c.id}`);
      this.success.set({ key: 'FORM.DELETED', params: { name } });
    } catch (e) {
      this.pageError.set(e instanceof ApiError ? e : null);
    }
    await this.reload();
  }
}
