    6.1. 示例 21：双语应用

    [RdvMedecins]应用提供法语和英语两种语言。在[NestJS]课程中，服务器在发送页面之前负责翻译页面。现在，页面在浏览器中生成：由客户端翻译页面，切换语言不再需要与服务器进行任何交互。

    [Angular] 有自己的翻译系统[@angular/localize]，它会为每种语言生成一个编译后的应用：因此切换语言只需加载另一个应用。我们将改用[ngx-translate]库，它是与[Angular]搭配使用最广泛的库，它在运行时进行翻译：只需点击一下，就能重新翻译整个页面。

    // =========================================================================
// 21-i18n/src/app/i18n/i18n.ts - the configuration of ngx-translate
// -------------------------------------------------------------------------
// ngx-translate is the most widely used translation library with
// Angular. We provide it with:
//   - a DICTIONARY per language (fr.json, en.json), where each text has a
//     KEY ("HOME.HELLO"); the parameters are written {{name}};
//   - a LOADER (TranslateLoader), which returns the dictionary of a
//     language. Ours takes them from the code of the application (import of
//     JSON files); another one could download them;
//   - the starting language (the one stored in localStorage, otherwise that
//     of the browser, otherwise English) and the fallback language.
// In the templates, {{ 'HOME.HELLO' | translate: { name: 'Marie' } }}
// displays the text of the CURRENT language; changing the language updates
// the whole page.
//
// It is, on the client side, the same principle as the NestJS course (dictionaries
// i18n/*.json + helper {{t}}) - but the translation is now done in
// the browser, and changing the language no longer asks anything of the server.
//
// (Angular also has its own system, @angular/localize, which builds ONE
// compiled application per language: the language can then only be changed
// by changing page. ngx-translate, on the other hand, translates at runtime.)
// =========================================================================

import { Provider } from '@angular/core';
import { provideTranslateLoader, provideTranslateService, TranslateLoader, TranslationObject } from '@ngx-translate/core';
import { Observable, of } from 'rxjs';
import fr from './fr.json';
import en from './en.json';

export type Language = 'fr' | 'en';
export const LANGUAGES: Language[] = ['fr', 'en'];
export const LANGUAGE_KEY = 'example21.language';

// the loader of the dictionaries
class DictionariesLoader implements TranslateLoader {
  getTranslation(language: string): Observable<TranslationObject> {
    return of(language === 'en' ? en : fr);
  }
}

function initialLanguage(): Language {
  const stored = localStorage.getItem(LANGUAGE_KEY);
  if (stored === 'fr' || stored === 'en') {
    return stored;
  }
  return navigator.language.startsWith('fr') ? 'fr' : 'en';
}

export function provideI18n(): Provider[] {
  return provideTranslateService({
    loader: provideTranslateLoader(DictionariesLoader),
    fallbackLang: 'en', // a key missing in French: the English one is used
    lang: initialLanguage(),
  });
}
    • 第 29–30 行：字典作为模块导入；它们是应用代码的一部分。这得益于[resolveJsonModule]选项，该选项位于[tsconfig.json]文件中；
    • 第 34 行：所选语言在[localStorage] 中存储时使用的键（示例 20）；
    • 第 37–41 行：字典加载器：[ngx-translate] 调用它，以可观察对象的形式获取某种语言的字典。我们的加载器从代码中获取字典；另一种加载器也可以从服务器下载字典；
    • 第 43–49 行：源语言：用户上次选择的语言；否则，如果浏览器语言为法语，则为法语；否则为英语；
    • 第 51–57 行：[provideTranslateService] 使[ngx-translate] 的服务在整个应用中可用。[fallbackLang]：当当前字典中缺少某个键时所使用的语言。

    // =========================================================================
// 21-i18n/src/app/i18n/plural.pipe.ts - choosing the plural form
// -------------------------------------------------------------------------
// ngx-translate does not handle plurals. The dictionary gives the
// forms under one same key ("APPOINTMENTS": { "zero", "one", "other" }) and
// this pipe chooses the right one, depending on the number and the language:
//     {{ 'HOME.APPOINTMENTS' | plural: n : language | translate: { n } }}
// Intl.PluralRules knows the rules of each language ("one" or "other" in
// English as in French, but other forms in Polish, in Arabic...).
// =========================================================================

import { Pipe, PipeTransform } from '@angular/core';

@Pipe({ name: 'plural' })
export class PluralPipe implements PipeTransform {
  transform(key: string, n: number, language: string | null): string {
    if (n === 0) {
      return `${key}.zero`;
    }
    return `${key}.${new Intl.PluralRules(language ?? 'en').select(n)}`;
  }
}
    • 第 16–21 行：该管道接收一个键（[HOME.APPOINTMENTS]）、一个数字和一种语言；它返回正确形式的键（例如[HOME.APPOINTMENTS.one]）；
    • 第 18 行：零有自己的格式（“没有预约”）；
    • 第 20 行：由浏览器提供的[Intl.PluralRules]遵循每种语言的规则：法语和英语使用[one] 或[other] ，而波兰语或阿拉伯语则有其他形式。（注意：在法语中，1.5 是单数；在英语中，它是复数。）

    // =========================================================================
// 21-i18n/src/app/app.ts - a translated page
// -------------------------------------------------------------------------
//   - 'KEY' | translate                    a text;
//   - 'KEY' | translate: { name: ... }     a text with parameters;
//   - date / currency with the language    a date, an amount, in the format
//                                          of the current language;
//   - translate.use('fr')                  changes the language: the whole
//                                          page is translated again.
// TranslateService.currentLang is a SIGNAL: the current language.
// =========================================================================

import { Component, effect, inject, signal } from '@angular/core';
import { CurrencyPipe, DatePipe } from '@angular/common';
import { TranslatePipe, TranslateService } from '@ngx-translate/core';
import { LANGUAGE_KEY, Language, LANGUAGES } from './i18n/i18n';
import { PluralPipe } from './i18n/plural.pipe';

@Component({
  selector: 'app-root',
  imports: [CurrencyPipe, DatePipe, TranslatePipe, PluralPipe],
  templateUrl: './app.html',
})
export class App {
  private readonly translate = inject(TranslateService);
  protected readonly language = this.translate.currentLang;
  protected readonly languages = LANGUAGES;
  protected readonly count = signal(2);
  protected readonly today = new Date();

  // what the RdvMedecins server would return (see the chapter on the black box)
  protected readonly serverResponses = [
    { statusCode: 409, key: 'ERRORS.LOGIN_TAKEN', params: {} },
    { statusCode: 429, key: 'ERRORS.TOO_MANY_ATTEMPTS', params: { minutes: '15' } },
  ];

  // translate.translate(key): a SIGNAL that follows the current language
  private readonly title = this.translate.translate('APP.TITLE');

  constructor() {
    // on each change of language: we store it, and we update
    // the lang attribute of the page (useful to screen readers, spell checkers)
    effect(() => {
      const language = this.language();
      if (language) {
        localStorage.setItem(LANGUAGE_KEY, language);
        document.documentElement.lang = language;
      }
      document.title = String(this.title());
    });
  }

  protected choose(language: Language): void {
    this.translate.use(language);
  }
}
    • 第 21 行：[TranslatePipe]：管道[translate]；
    • 第 25 行：[TranslateService]：[ngx-translate]的主服务；
    • 第 26 行：[currentLang]：当前语言，以信号的形式提供；
    • 第 32–35 行：两个错误响应，与服务器返回的形式一致：一个键和若干参数；
    • 第 38 行：[translate.translate(key)] 返回一个信号 ，其值等于该键的翻译，并随当前语言变化；
    • 第 43–50 行：每当语言改变时执行的动作：保存语言（第 46 行），更新页面的[lang]属性（第 47 行；屏幕阅读器和拼写检查器会用到它），以及标签页标题（第 49 行）；
    • 第 54 行：[use] 更改当前语言：整个页面被重新翻译。

  <div class="d-flex justify-content-between align-items-center mb-3">
    <h1 class="h3 mb-0">{{ 'APP.TITLE' | translate }}</h1>
    <div class="btn-group btn-group-sm" role="group" [attr.aria-label]="'APP.LANGUAGE' | translate">
      @for (l of languages; track l) {
        <button class="btn" [class]="language() === l ? 'btn-primary' : 'btn-outline-primary'" (click)="choose(l)">
          {{ l.toUpperCase() }}
        </button>
      }
    </div>
  </div>

  <div class="card p-3 mb-3">
    <p>{{ 'HOME.HELLO' | translate: { name: 'Marie' } }}</p>
    <!-- a parameter computed by another pipe, in the current language -->
    <p>{{ 'HOME.TODAY' | translate: { date: (today | date: 'fullDate' : '' : language() ?? 'en') } }}</p>
    <p>{{ 'HOME.PRICE' | translate: { price: (1234.5 | currency: 'EUR' : 'symbol' : '1.2-2' : language() ?? 'en') } }}</p>
    <!-- plural chooses the key (zero, one, other), translate translates it -->
    <p class="fw-bold">{{ 'HOME.APPOINTMENTS' | plural: count() : language() | translate: { n: count() } }}</p>
    <div class="d-flex gap-2">
      <button class="btn btn-sm btn-outline-success" (click)="count.set(count() + 1)">{{ 'HOME.ADD' | translate }}</button>
      <button class="btn btn-sm btn-outline-secondary" [disabled]="count() === 0" (click)="count.set(count() - 1)">
        {{ 'HOME.REMOVE' | translate }}
      </button>
    </div>
  </div>

  <div class="card p-3">
    <h2 class="h6">{{ 'SERVER.TITLE' | translate }}</h2>
    <p>{{ 'SERVER.EXPLANATION' | translate }}</p>
    <ul class="mb-0">
      @for (r of serverResponses; track r.key) {
        <!-- the key of the server IS a key of the dictionary; params provides its parameters -->
        <li><code>{{ r.statusCode }} {{ r.key }}</code><br>&rarr; {{ r.key | translate: r.params }}</li>
      }
    </ul>
  </div>
</div>
    • 第 3 行：['APP.TITLE' | translate]：该键在当前语言中的翻译；
    • 第 6 行：当前语言的按钮高亮显示；
    • 第 14 行：带参数的文本：管道接收一个对象，该对象提供每个参数的值；
    • 第 16–17 行：参数的值可以由另一个管道计算得出。[date] 和[currency] 的最后一个参数是语言：日期和金额按法语或英语的风格书写；
    • 第 19 行：两个链式管道：[plural] 选择键，[translate] 翻译该键；
    • 第 34 行：服务器返回的键连同其参数一起被翻译。
