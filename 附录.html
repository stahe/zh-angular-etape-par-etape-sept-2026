    13. 附录

    13.1. 安装 Node.js

    [Node.js] 可从 nodejs.org 下载：选择 LTS（长期支持）24 版本，或从 22.22.3 开始的 22 版本：这些是 [Angular] 22 所要求的版本。[Windows] 安装程序也会安装 [npm]。在控制台中验证安装：

    node --version
npm --version

    要在同一台机器上运行多个版本的 [Node.js] ，可以使用 [nvm-windows] （在 [Windows] 下）或 [nvm]（在 [Linux] 和 [macOS]下）。

    示例和案例研究不需要安装任何全局工具：[Angular CLI] （[ng] 命令）、[Angular] 编译器、[TypeScript] （以及服务器端的 [nest] 工具）都是每个项目依赖项的一部分，由 [npm install] 安装。[package.json] 中的脚本（[npm start]、[npm run build]）会在 [node_modules] 文件夹中找到这些工具。 如果要自己创建新项目，可以使用 [npx @angular/cli new my-project] ，无需安装任何东西。

    13.2. 安装 Visual Studio Code

    [Visual Studio Code] 可从 code.visualstudio.com 下载。对于 [Angular]，请从扩展面板（Ctrl+Shift+X）安装 Angular Language Service 扩展（Angular 编辑器）：提供模板中的代码补全和类型检查、从选择器（[<app-input-field>]）到组件类的导航、从 [templateUrl] 到模板文件的导航，以及在输入时实时高亮显示 [Angular] 编译器错误。

    通过 File / Open Folder 菜单打开项目（例如 [examples-angular] 文件夹），并通过 Terminal / New Terminal 菜单在其中打开控制台。

    13.3. Angular DevTools 扩展

    Angular DevTools 扩展可以安装，从 [Chrome]、[Edge] 或 [Firefox] 的扩展商店获取。它会在浏览器的开发者工具（F12）中添加一个“Angular”标签页，对于以开发模式运行的应用程序，它会显示以下内容：

    • 页面的组件树，以及每个组件的输入、输出和属性（信号及其值）；
    • 组件的信号图：哪个 [computed] 依赖于哪个信号；
    • 已注入的服务和注入器树；
    • 路由器的路由；
    • 分析器，用于测量更新每个组件所花费的时间。

    你可以在那里修改某项数据并观察页面更新：这是理解响应性的绝佳方式。

    13.4. 使用 Laragon 安装 MySQL

    JSON 服务器需要 [MySQL] （或 [MariaDB]）。[Laragon] （laragon.org）在 [Windows] 下安装其中一个，开箱即用，并附带 [HeidiSQL] 管理工具。安装之后：

    • “Start All”按钮会在 3306 端口上启动 [MySQL] 服务器；
    • 用户 [root] 没有密码：这些是服务器 [.env.example] 文件中的默认值；
    • 在 [HeidiSQL] 中（“Database”按钮），File / Run SQL 菜单项会运行 [database/dbrdvmedecins2.sql] 脚本。

    在 [Linux] 或 [macOS] 中，使用系统的包管理器安装 [MySQL] 或 [MariaDB] ，并使用命令行客户端运行该脚本：[mysql -u root -p < database/dbrdvmedecins2.sql]。

    13.5. 安装 curl

    [curl] 包含在 [Windows] 10 和 11 版本、[macOS] 以及大多数 [Linux] 发行版中。检查其版本：

    curl --version

    本文档中使用的 [--json] 选项自 7.82 版本（2022 年）起可用。如果你使用的是较旧的版本，请将 [--json @file] 替换为 [-H "Content-Type: application/json" -d @file]，或从 curl.se 安装较新的版本。

    在 [PowerShell] 中，必须输入 [curl.exe]，而不是 [curl]：在 [PowerShell] 中，[curl] 是另一个命令（[Invoke-WebRequest]）的别名，该命令不包含 [curl] 的选项。命令提示符（[cmd]）则没有这个问题。
